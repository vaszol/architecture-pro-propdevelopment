# Список требований
## Общие требования к безопасности
- хранить данные в зашифрованном виде
- дать пользователю возможность управлять своими данными(номера машин, квартир, проездов)
- Использовать случайные и сложные идентификаторы, например UUID
- Установить строгие проверки прав доступа
## Протоколы аутентификации и авторизации
- Использовать защищённые каналы передачи данных (HTTPS, VPN)
- Реализовать проверку целостности сообщений (например, с использованием цифровых подписей или HMAC) для предотвращения изменения данных при передаче.
- Использовать случайные и сложные идентификаторы, например UUID

## Взаимодействие
- Использовать единые и обобщённые сообщения об ошибках, чтобы не раскрывать информацию о существовании учётной записи
- не использовать персональные данные пользователей
- Использовать защищённые каналы передачи данных (HTTPS, VPN)
- предоставить API для мобильной платформы
