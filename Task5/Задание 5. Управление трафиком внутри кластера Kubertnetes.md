Задание 5. Управление трафиком внутри кластера Kubertnetes

# Инструкция запуска
## 1. Запустить Minikube:
```shell
minikube start
```

## 2. развернуть сервисы (Pod)

```shell
#!/bin/bash
echo "[INFO] Создаётся pod front-end-app"
kubectl run front-end-app --image=nginx --labels role=front-end
echo "[INFO] Создаётся pod back-end-api-app"
kubectl run back-end-api-app --image=nginx --labels role=back-end-api
echo "[INFO] Создаётся pod admin-front-end-app"
kubectl run admin-front-end-app --image=nginx --labels role=admin-front-end
echo "[INFO] Создаётся pod admin-back-end-api-app"
kubectl run admin-back-end-api-app --image=nginx --labels role=admin-back-end-api
```

## 3. Примените сетевую политику
```shell
kubectl apply -f non-admin-api-allow.yaml
```

## 4. проверка
- Получаем ip-адрес pod
```shell
kubectl get pods -o wide
```

Проверить доступ (заменить apiserver = нужный ip-адрес)
